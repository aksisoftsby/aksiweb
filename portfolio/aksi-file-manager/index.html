Aksi File Manager — Pengelola Berkas Android

Pengelola berkas Android: jelajah folder, arsip ZIP/7Z/RAR, editor gambar, PDF, FTP/SFTP, pemindai QR. Semua diproses lokal di perangkat.

Google Play ↗ Buat proyek serupa

Tentang Proyek

Aksi File Manager adalah pengelola berkas Android yang menggabungkan pekerjaan yang biasanya tersebar di beberapa aplikasi: menjelajah folder, membuka arsip, mengedit gambar, membaca PDF, mengedit dokumen, sampai mengunggah berkas ke server FTP/SFTP. Semua proses berjalan lokal di perangkat — berkas pengguna tidak pernah diunggah ke server kami.

Aplikasi ini ditujukan untuk pemakaian harian yang cepat: buka folder, cari berkas, salin atau pindahkan, lalu langsung tangani isinya tanpa berpindah aplikasi.

Fitur yang Jalan

  • Peramban berkas dengan tampilan Grid, List, dan Sistem berkas untuk penyimpanan internal maupun kartu SD
  • Operasi berkas lengkap: salin, pindah, ganti nama, hapus, buat folder baru, serta buat berkas teks, Markdown, atau HTML
  • Pencarian cepat di semua direktori yang bisa dijangkau, termasuk berkas tersembunyi
  • Multi-pilih dengan tekan lama untuk salin, pindah, bagikan, atau hapus massal
  • Editor gambar: crop, rasio tetap, putar/flip, filter, kecerahan, kontras, dan saturasi
  • PDF: penampil pinch-zoom, ekstraksi dan penggabungan teks, pemisahan halaman, serta cap teks
  • Arsip: buka dan ekstrak ZIP, 7Z, RAR, TAR, TAR.GZ, GZ; buat arsip ZIP, 7Z, dan TAR.GZ
  • Dokumen: lihat dan edit DOCX, XLSX, PPTX, serta CSV
  • Editor teks/kode dengan nomor baris, penyorotan sintaks, dan cari & ganti
  • Peralatan penyimpanan: penganalisis folder terbesar, pembersih berkas sementara/log/folder kosong, dan pendeteksi berkas duplikat
  • Info aplikasi terpasang dengan ekspor/bagikan APK
  • Klien FTP, FTPS eksplisit, dan SFTP; profil server disimpan terenkripsi (AES/GCM) di Android Keystore, mendukung unggah/unduh multi-berkas dan unduh folder rekursif
  • Pemindai QR/barcode lewat kamera atau dari gambar yang sudah ada
  • Kunci aplikasi dengan PIN (hash terenkripsi lokal), bahasa Indonesia & Inggris, tema gelap/terang/sistem

Hasil & Angka

6 format arsip

ZIP, 7Z, RAR, TAR, TAR.GZ, GZ — plus membuat ZIP, 7Z, TAR.GZ

3 protokol jaringan

FTP, FTPS eksplisit, dan SFTP dengan profil terenkripsi

4 format dokumen

DOCX, XLSX, PPTX, dan CSV bisa dibuka serta diedit

0 unggahan ke server

Seluruh pemrosesan berkas berjalan di perangkat
