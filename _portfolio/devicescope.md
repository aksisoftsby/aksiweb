## Tentang Proyek

DeviceScope adalah aplikasi Android utilitas untuk membaca detail perangkat Android secara cepat dan akurat — informasi perangkat, kapasitas RAM dan storage, level baterai, resolusi dan kepadatan display, sampai daftar sensor dan fitur sistem. Semuanya disajikan dalam UI terminal gelap yang ringan dibaca.

## Yang Dikerjakan

- Halaman overview perangkat: identitas (manufacturer, model, chipset/CPU, versi Android)
- Panel CPU & SoC: distribusi CPU core, arsitektur ABI, dan info manufacturer SoC
- Monitoring baterai: level baterai, status charging, tegangan, teknologi baterai, dan suhu
- Detail display: resolusi, ukuran layar, kerapatan piksel, refresh rate, dan display mode
- Panel RAM & storage beserta proporsi penggunaan memori dan penyimpanan
- Pembacaan sensor perangkat (accelerometer, gyroscope, magnetometer, ambient light, dan lainnya) lengkap dengan vendor dan resolusi masing-masing sensor
- Halaman pengaturan aplikasi: pilihan bahasa, tema sistem/terang/gelap, dan ringkasan info aplikasi

## Catatan Teknis

- Rilis publik melalui Google Play dengan package id.aksisoft.devicescope
- Tanpa izin sensitif — aplikasi hanya membaca informasi sistem yang tersedia sehingga aman untuk privasi pengguna
- UI bergaya terminal gelap dengan aksen hijau neon agar konsisten dengan tema dev-tool
